## Lab Activities

The 8 labs form one connected practical journey. Complete them in order so each verified output can support the activities that follow.

| # | Activity | Outcome |
|---:|----------|---------|
| **1** | [Set Up and Access Gemini AI in Google Sheets](labs/lab-01-set-up-and-access-gemini-ai-in-google-sheets.md) | Open the sample sheet, make your own copy, open the Gemini side panel, and run a first AI prompt on the data. |
| **2** | [Generate and Explain Formulas with AI](labs/lab-02-generate-and-explain-formulas-with-ai.md) | Use AI to generate a spreadsheet formula from a plain-language description, and to explain an existing formula. |
| **3** | [Combine and Troubleshoot Formulas with AI](labs/lab-03-combine-and-troubleshoot-formulas-with-ai.md) | Use AI to build a multi-step formula, then diagnose and fix a broken one against a value you can confirm. |
| **4** | [Write Effective Prompts for Spreadsheet Tasks](labs/lab-04-write-effective-prompts-for-spreadsheet-tasks.md) | Compare a vague prompt with a specific one and capture a reusable four-part prompt pattern for spreadsheet work. |
| **5** | [Clean, Transform and Organise Data with AI](labs/lab-05-clean-transform-and-organise-data-with-ai.md) | Use AI to standardise messy text and dates, tidy fields, and organise the dataset into a clean table. |
| **6** | [Summarise and Analyse Your Dataset with AI](labs/lab-06-summarise-and-analyse-your-dataset-with-ai.md) | Use AI to summarise the dataset and answer analytical questions, verifying every figure against a formula. |
| **7** | [Create Tables, Charts and Visualisations with AI](labs/lab-07-create-tables-charts-and-visualisations-with-ai.md) | Use AI to build a summary/pivot table and the right, clearly labelled chart to tell the data's story. |
| **8** | [Validate AI Output and Apply AI Safely to Work Data](labs/lab-08-validate-ai-output-and-apply-ai-safely-to-work-data.md) | Stress-test AI output for accuracy and write a personal checklist for applying AI safely to real work data. |

## About

This repository contains the complete lab and courseware package for **AI Application for Google Sheet** (**C817**) by Tertiary Courses / Tertiary Infotech. The practical activities build progressively from **Set Up and Access Gemini AI in Google Sheets** to **Validate AI Output and Apply AI Safely to Work Data**, with explicit checks that help learners verify each result before moving on.

- Complete **8 connected hands-on activities** and carry their outputs through one coherent learning journey.
- Practise with **Google Gemini · Google Sheets · Spreadsheet** and the supporting resources supplied in the repository.
- Begin with **Set Up and Access Gemini AI in Google Sheets** and finish with **Validate AI Output and Apply AI Safely to Work Data**.

## Getting Started

### Prerequisites

- The accounts and software required for **Google Gemini · Google Sheets · Spreadsheet**. Follow the setup and access notes in each lab.
- Review [`labs/tools.md`](labs/tools.md) before class for environment, account and safe-use requirements.
- A modern web browser and Git for cloning the materials.
- Synthetic or authorised data only. Do not place secrets, personal data or confidential material into an unapproved service.
- A named human reviewer for facts, calculations, decisions and any externally released output.

### 1. Clone the repository

```bash
git clone https://github.com/tertiarycourses/C817---AI-Application-for-Google-Sheet.git
cd C817---AI-Application-for-Google-Sheet
```

### 2. Open the lab index

Start with [labs/README.md](labs/README.md), then complete Labs 1–8 in order. Each lab provides the activity context, practical steps and a way to verify the result.

### 3. Keep your connected outputs

Store each lab output in the suggested working folder and retain the evidence or review notes requested by the lab. Later activities depend on these approved outputs.
